# Boi Para 📚

Boi Para is a full-stack MERN web application focused on buying and selling old books online. The platform helps students and readers find affordable second-hand books while also giving users an easy way to sell their unused books.

---

## 🚀 Features

- User Authentication (Login & Register)
- Add and Manage Book Listings
- Browse Available Books
- Search Books
- View Book Details
- Direct Buyer-Seller Connection
- Image Upload Support
- Responsive User Interface
- REST API Integration

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Other Tools & Services
- Cloudinary
- Git & GitHub

---

## 🎯 Problem It Solves

Many students and readers struggle to find affordable books, while old books often remain unused after exams or semesters. Boi Para provides a simple platform where users can directly buy and sell second-hand books online instead of depending on local markets or social media groups.

---

## 👥 Target Users

- Students
- Readers
- People looking for affordable second-hand books
- Users who want to sell unused books

---

## ⚙️ Technical Approach

The frontend was developed using HTML, CSS, and JavaScript to create a responsive and user-friendly interface. The backend was built using Node.js and Express.js with REST APIs for handling user and book-related operations. MongoDB Atlas is used for storing user information and book listings, while Cloudinary is used for image upload and storage.

## 📦 Installation

### Clone the Repository


